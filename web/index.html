02

The whole surface

No hidden modes. Payload goes to stdout, decoration to stderr, so every command composes with the shell you already use.

clidev pastealias: clp

Screenshot → validated PNG → absolute path on the clipboard. Windows uses PowerShell STA and .NET; macOS uses pngpaste or osascript; Linux uses wl-paste or xclip.

--at--base64--out--keep--no-copy--json
clidev watch <cmd>clidev notify

Spawns the command with inherited stdio, forwards signals to the whole process group, and reports success, failure and duration.

--title--sound--no-bell--only-fail--quiet--json
clidev hooksStop + Notification · Claude Code

Injects the two hooks that matter, backs the file up, and refuses to touch JSON it cannot parse. Re-running is a no-op, not a duplicate.

--claude--dry-run--remove--no-backup--command
clidev cleanstdin or --file

Pipe filter for logs you are about to paste. ANSI out, secrets masked, stack frames folded, cleaned text on stdout and the clipboard.

--file--no-copy--keep-frames--keep-duplicates--json
clidev pack [globs…]git-changed → src/**/*

One markdown bundle with a tree, language fences and a token estimate. Binary files, lockfiles and node_modules never make it in.

--all--print--out--no-copy--max-bytes--max-tokens--json

04

Your agents should tell you when they stop

Not make you check. clidev installs the two lifecycle hooks that matter and leaves the rest of your config exactly as it found it.

Stop and Notification, wired to clidev notify.

clidev hooks --claude writes into ~/.claude/settings.json (or $CLAUDE_CONFIG_DIR). The bell rings and a native toast appears the moment a task ends or waits for permission.

  • Atomic. Temp file, then rename. A crash can't leave you with half a config.
  • Idempotent. Running it twice updates the command in place instead of duplicating the hook.
  • Reversible. --remove strips only clidev entries and deletes the event if it becomes empty.
  • Portable. Falls back to node <abs>/dist/index.js when clidev isn't on PATH.

Antigravity, OpenCode, Aider:
clidev watch "opencode" --title OpenCode

~/.claude/settings.jsonafter --claude
{
  "hooks": {
    "Stop": [{
      "hooks": [{
        "type": "command",
        "command": "clidev notify --title \"Claude Code\"",
        "timeout": 10
      }]
    }],
    "Notification": [{
      "hooks": [{
        "type": "command",
        "command": "clidev notify --title \"Claude Code\"",
        "timeout": 10
      }]
    }]
  }
}
05

Three commands, nothing to configure

No daemon, no account, no background service. Build it once, link the two binaries, and keep working in the shell you already have open.

Clone and build

git clone <repo> clidev
cd clidev
npm install
npm run build

Link the binaries

npm link

clidev --version
clp --help

Wire your agent

clidev hooks --claude
clidev watch "npm run build"
